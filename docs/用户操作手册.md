## 1. 系统概述

### 1.1 系统简介

福礼社平台是一款企业福利采购平台，致力于为企业提供一站式福利采购解决方案。平台支持多租户架构，每个租户可独立管理自己的商品、订单、支付等业务。

### 1.2 技术架构

- **前端技术栈**: Vue 3 + TypeScript + Element Plus + Vite
- **后端技术栈**: Spring Boot 3 + Spring Cloud + MyBatis Plus + MySQL
- **认证方式**: JWT Token认证
- **数据库**: MySQL 8.0 (生产环境) / H2 (测试环境)

### 1.3 访问地址

- **管理后台**: http://localhost:3100
- **H5移动端**: http://localhost:3001 (待部署)

## 2. 登录与权限

### 2.1 登录页面

访问管理后台首页，显示登录界面：

| 字段 | 说明 | 必填 |
|------|------|------|
| 用户名 | 用户登录账号 | 是 |
| 密码 | 用户登录密码 | 是 |
| 验证码 | 随机生成的4位验证码 | 是 |

**操作步骤**:
1. 在浏览器中输入管理后台地址
2. 输入用户名和密码
3. 输入验证码（点击可刷新）
4. 点击"登录"按钮

### 2.2 默认账号

| 用户名 | 密码 | 租户 | 角色 |

| admin | 123456 | 南樾星数字科技 | 超级管理员 |

| fulishe_admin | 123456 | 福礼社运营中心 | 管理员 |

### 2.3 权限说明

系统采用RBAC权限模型：

- **超级管理员**: 拥有所有权限，可管理所有租户数据
- **租户管理员**: 拥有本租户的管理权限
- **普通用户**: 仅拥有基础操作权限

## 3. 系统管理

### 3.1 用户管理

#### 3.1.1 功能概述

用户管理模块用于管理系统内的所有用户，包括新增、编辑、删除、查询等操作。

#### 3.1.2 操作指南

**查询用户**:
1. 点击左侧菜单"系统管理" -> "用户管理"
2. 在搜索框中输入用户名/真实姓名/手机号
3. 选择用户状态（启用/禁用）
4. 点击"查询"按钮

**新增用户**:
1. 点击"新增用户"按钮
2. 填写用户信息：
   - 用户名：唯一标识
   - 密码：登录密码（建议6-20位）
   - 真实姓名：用户真实姓名
   - 手机号：用户手机号码
   - 邮箱：用户邮箱地址
   - 状态：启用/禁用
3. 点击"确定"按钮

**编辑用户**:
1. 在用户列表中找到目标用户
2. 点击"编辑"按钮
3. 修改用户信息
4. 点击"确定"按钮

**删除用户**:
1. 在用户列表中找到目标用户
2. 点击"删除"按钮
3. 确认删除操作

### 3.2 租户管理

#### 3.2.1 功能概述

租户管理模块用于管理平台的租户信息，支持多租户隔离。

#### 3.2.2 操作指南

**查询租户**:
1. 点击左侧菜单"系统管理" -> "租户管理"
2. 输入租户名称/编码进行搜索
3. 选择租户状态
4. 点击"查询"按钮

**新增租户**:
1. 点击"新增租户"按钮
2. 填写租户信息：
   - 租户名称：租户企业名称
   - 租户编码：唯一标识（英文大写）
   - 联系人：租户联系人姓名
   - 联系电话：租户联系电话
   - 状态：启用/禁用
3. 点击"确定"按钮

### 3.3 部门管理

#### 3.3.1 功能概述

部门管理模块用于管理企业组织架构，支持树形结构展示。

#### 3.3.2 操作指南

**查看部门树**:

   - 部门名称：部门名称
   - 上级部门：选择上级部门
   - 排序号：显示顺序
3. 点击"确定"按钮

### 3.4 角色管理

#### 3.4.1 功能概述

角色管理模块用于管理系统角色，配置角色权限。

#### 3.4.2 操作指南

## 5. 卡券管理

### 5.1 卡券模板

#### 5.1.1 功能概述

卡券模板模块用于创建和管理优惠券模板，支持批量发放。

#### 5.1.2 操作指南

**创建模板**:
1. 点击左侧菜单"卡券管理" -> "卡券模板"
2. 点击"新增模板"按钮
3. 填写模板信息：
   - 优惠券名称：模板名称
   - 面值：优惠金额
   - 最低消费：使用门槛
   - 发放数量：总发放量
   - 有效期：开始时间和结束时间
4. 点击"确定"按钮

**发放卡券**:
1. 在模板列表中找到目标模板
2. 点击"发放"按钮
3. 选择发放方式（全部用户/指定用户）
4. 输入发放数量
5. 点击"确定"按钮

### 5.2 卡券列表

#### 5.2.1 功能概述

#### 5.2.2 操作指南

2. 输入用户名称/手机号进行搜索
3. 选择卡券状态（未使用/已使用/已过期）
4. 点击"查询"按钮

### 5.3 发放批次

#### 5.3.1 功能概述

发放批次模块用于查看优惠券发放记录。

#### 5.3.2 操作指南

**查看批次**:

2. 查看发放批次列表

## 6. 订单管理

### 6.1 订单列表

#### 6.1.1 功能概述

订单列表模块用于管理用户订单，支持订单状态跟踪和操作。

#### 6.1.2 操作指南

**查询订单**:
1. 点击左侧菜单"订单管理" -> "订单列表"
2. 输入订单号/用户名称/手机号进行搜索
3. 选择订单状态：
   - 待付款：等待用户付款
   - 待发货：已付款，等待发货
   - 待收货：已发货，等待确认收货
   - 已完成：交易完成
   - 已取消：订单取消
   - 已退款：已退款
4. 点击"查询"按钮

**订单操作**:
| 操作 | 说明 | 适用状态 |
|------|------|----------|
| 发货 | 标记订单为已发货 | 待发货 |
| 确认收货 | 标记订单为已完成 | 待收货 |
| 取消订单 | 取消订单 | 待付款 |
| 退款 | 发起退款申请 | 已付款/已发货 |

### 6.2 订单详情

#### 6.2.1 功能概述

订单详情模块用于查看订单的详细信息，包括商品信息、支付信息、物流信息等。

#### 6.2.2 操作指南

**查看详情**:
1. 在订单列表中找到目标订单
2. 点击"详情"按钮
3. 查看订单详情：
   - 订单信息：订单号、创建时间、状态等
   - 商品列表：购买的商品明细
   - 支付信息：支付方式、金额、时间等
   - 收货信息：收货人、地址、电话等

## 7. 支付管理

### 7.1 支付记录

#### 7.1.1 功能概述

支付记录模块用于查看所有支付交易记录。

#### 7.1.2 操作指南

**查询支付记录**:
1. 点击左侧菜单"支付管理" -> "支付记录"
2. 输入支付单号/订单号进行搜索
3. 选择支付方式：
   - 微信支付
   - 支付宝
   - 银行卡
4. 选择支付状态：
   - 待支付
   - 支付中
   - 已支付
   - 已退款
5. 点击"查询"按钮

**查看支付详情**:
1. 在支付记录列表中找到目标记录
2. 点击"详情"按钮
3. 查看支付详情：
   - 支付单号
   - 订单号
   - 支付金额
   - 支付方式
   - 支付时间
   - 第三方支付单号

### 7.2 退款记录

#### 7.2.1 功能概述

退款记录模块用于管理退款申请和审核。

#### 7.2.2 操作指南

**查询退款记录**:
1. 点击左侧菜单"支付管理" -> "退款记录"
2. 输入退款单号/订单号进行搜索
3. 选择退款状态：
   - 待审核
   - 已同意
   - 已拒绝
   - 退款中
   - 已完成
4. 点击"查询"按钮

**审核退款**:
1. 在退款记录列表中找到待审核的记录
2. 点击"审核"按钮
3. 选择审核结果（同意/拒绝）
4. 填写审核意见
5. 点击"确定"按钮

### 7.3 支付配置

#### 7.3.1 功能概述

支付配置模块用于配置各支付渠道的参数。

#### 7.3.2 操作指南

**配置微信支付**:
1. 点击左侧菜单"支付管理" -> "支付配置"
2. 切换到"微信支付"标签页
3. 填写配置信息：
   - 商户号
   - APPID
   - API密钥
   - 回调地址
4. 点击"保存"按钮

**配置支付宝**:
1. 切换到"支付宝"标签页
2. 填写配置信息：
   - 商户号
   - APPID
   - 私钥
   - 公钥
   - 回调地址
3. 点击"保存"按钮

**配置银行卡支付**:
1. 切换到"银行卡"标签页
2. 填写配置信息：
   - 银行名称
   - 银行卡号
   - 开户名
3. 点击"保存"按钮

## 9. 常见问题

### 9.1 登录问题

**Q: 忘记密码怎么办？**
A: 请联系管理员重置密码。

**Q: 验证码无法刷新？**
A: 请检查网络连接，或尝试刷新页面。

### 9.2 权限问题

**Q: 为什么看不到某些菜单？**
A: 请联系管理员检查角色权限配置。

### 9.3 数据问题

**Q: 商品库存不足怎么办？**
A: 在商品SKU管理中增加库存数量。

**Q: 订单无法支付？**
A: 请检查支付配置是否正确，或联系支付渠道客服。

### 9.4 技术问题

**Q: 页面加载缓慢？**
A: 请检查网络连接，或清除浏览器缓存。

**Q: 系统报错怎么办？**
A: 请记录错误信息，联系技术支持。
