# 福礼社平台 · 业务与技术术语表

> 适用范围：管理后台（Vue3 + Element Plus）、H5 商城（Vue3 + Vant）、小程序（Taro）、Mock API（Node/Express）。
> 用途：统一产品、研发、测试、运营对同一概念的口径，作为接口字段、页面文案、验收标准的共同基线。

## 1. 平台与角色

| 术语 | 英文/字段 | 定义 |
| --- | --- | --- |
| 平台 | Platform | 福礼社运营方，负责租户、菜单权限、平台抽佣、分销合规与全局数据。 |
| 租户 | tenant / tenantId | 平台内独立经营主体，拥有独立用户、商品、订单数据。 |
| 商户 | merchant / merchantId | 实际经营店铺的租户，商品、采购、结算、发票均归属商户。 |
| 供应商 | supplier / supplierId | 向商户供货的主体，可查看本人采购单、接单、发货并对账。 |
| 分销商 | distributor / distributorId | 推广商品并获得佣金的角色，平台上限二级。 |
| 消费者 | user / userId | H5/小程序下单用户，默认演示用户 `userId=2`。 |
| 数据范围 | dataScope | `ALL / MERCHANT / SUPPLIER / DISTRIBUTOR / SELF`，决定行级数据可见范围。 |
| 权限码 | permission | 菜单级权限标识，如 `product:spu`、`pay:invoice`、`pay:commission`。 |
| 超级管理员 | super_admin | 拥有 `*:*:*` 通配权限与全量数据。 |

## 2. 商品与履约

| 术语 | 英文/字段 | 定义 |
| --- | --- | --- |
| SPU | Standard Product Unit / spuId | 标准化商品单元（如“中秋礼盒”），承载名称、图片、类目、品牌。 |
| SKU | Stock Keeping Unit / skuId | 最小库存单位（规格/包装），价格与库存落在 SKU。 |
| 可售库存 | availableStock | `stock - lockedStock`，下单校验以可售库存为准。 |
| 锁定库存 | lockedStock | 下单后预占、支付前冻结的数量，30 分钟未支付可释放。 |
| 库存台账 | inventory | 按仓库 + SPU/SKU 维度记录库存与预警线。 |
| 仓储预警 | warningLine / status | 可用库存低于预警线为 `warning`，低于约 40% 为 `danger`。 |
| 溯源 | trace / traceCode | 一物一码的原料—生产—检测—仓储—物流—签收链路存证。 |
| 卡券 | coupon | 可核销/转赠的权益凭证，关联卡券模板与批次。 |
| 卡券模板 | couponTemplate | 定义面值/折扣、门槛、有效期、发放上限。 |
| 发放批次 | couponBatch | 一次批量发放记录，统计发放/领取/核销数。 |
| 福卡 | fuliCard / 福礼社卡 | 平台模拟资金账户，可充值、支付、退款。 |
| 一物一码 | one-code-one-item | 每个卡券/商品实例唯一溯源码。 |

## 3. 订单与售后

| 术语 | 英文/字段 | 定义 |
| --- | --- | --- |
| 订单 | order / orderNo | 一次交易主单，金额、状态、收货信息与商品明细的集合。 |
| 订单明细 | orderItem | 订单内单个 SKU 的数量、单价、小计与归因快照。 |
| 下单预占 | reserve | 创建订单时锁定库存，不扣减真实库存。 |
| 支付扣减 | commit | 支付成功后将锁定库存转为真实扣减。 |
| 回补库存 | restock | 取消/退款/售后通过后把库存加回。 |
| 售后 | refund | 退款申请与审核流程，包含待审核、处理中、完成、驳回。 |
| 原路退回 | refund to source | 退款沿原支付渠道退回（Mock 仅记录单号）。 |
| 部分退款 | partial refund | 退款金额小于订单实付金额。 |
| 确认收货 | complete | 用户确认收货，订单完成并触发佣金 T+N 起算。 |
| 签收 | receive | 采购到货签收，记录签收人与签收时间。 |

## 4. 营销与分销

| 术语 | 英文/字段 | 定义 |
| --- | --- | --- |
| 满减 | full reduction | 订单金额达到门槛后减免固定金额，支持多档取最优。 |
| 门槛金额 | thresholdAmount | 触发满减的最低商品金额。 |
| 优惠金额 | discountAmount | 满减实际减免金额，订单金额与实付据此计算。 |
| 佣金规则 | distributionRule | 按 SPU 配置一级/二级佣金率、有效期、结算周期。 |
| 佣金率 | commissionRate / rateBp | 百分比展示，底层用基点 `bp`（100bp=1%）。 |
| 一级佣金 | level 1 / DIRECT | 直接分享人获得的佣金。 |
| 二级佣金 | level 2 / TEAM | 分享人的上级获得的团队佣金，平台上限二级。 |
| 归因 | attribution | 下单时记录分享人、规则、二级上级，支付后据此计提。 |
| 自购返佣 | self-purchase | 分销商购买自己分享的商品，不计佣金（合规）。 |
| T+N | settleDays / settleableTime | 订单完成后 N 天佣金才可结算。 |
| 可结算 | SETTLEABLE | 已过 T+N 冻结期，可执行结算。 |
| 已结算 | SETTLED | 佣金已出账。 |
| 失效 | INVALID | 退款后佣金冲正置为失效。 |

## 5. 资金、结算与发票

| 术语 | 英文/字段 | 定义 |
| --- | --- | --- |
| 资金流水 | fundFlow | 所有资金动作的台账，金额以“分”存储。 |
| 支付入账 | PAY_IN | 订单支付成功入账。 |
| 退款出账 | REFUND_OUT | 退款原路出账。 |
| 佣金计提 | COMMISSION_ACCRUAL | 支付成功按规则计提佣金。 |
| 佣金冲正 | COMMISSION_REVERSE | 退款时反向冲销佣金。 |
| 佣金结算 | COMMISSION_SETTLE | 佣金实际出账。 |
| 平台技术服务费 | PLATFORM_FEE | 平台按实付金额 × 费率抽取的收入。 |
| 平台服务费冲正 | PLATFORM_FEE_REVERSE | 退款时冲销平台服务费。 |
| 商户应结分账 | MERCHANT_SPLIT | 实付金额扣除平台服务费后应结算给商户的金额。 |
| 供应商成本 | supplierCost | 订单商品采购成本合计，用于供应商侧分账参考。 |
| 分账单 | split / splitNo | 一次订单的多主体分账记录（平台/商户/供应商/分销商）。 |
| 结算单 | settlement / settlementNo | 供应商维度的对账结算单据。 |
| 发票 | invoice / invoiceNo | 消费者就订单申请的税务凭证。 |
| 电子普通发票 | invoiceType=1 | 个人或企业可申请，通常无需税号。 |
| 增值税专用发票 | invoiceType=2 | 必须填写纳税人识别号。 |
| 发票抬头 | buyerName / titleType | 个人姓名或企业名称。 |
| 红冲 | redFlush | 对已开具发票做负数冲销，保留原票与红冲单号。 |
| 发票勾稽 | invoice reconciliation | 发票金额、税额与订单实付金额一致。 |

## 7. 技术与研发术语

| 术语 | 定义 |
| --- | --- |
| Mock API | `frontend/admin/mock-server.cjs` + `mock/routes-*.cjs`，内存数据，重启即重置。 |
| 种子数据 | `mock/seed.cjs`、`mock/seed-extra.cjs`，服务启动时构建的演示数据。 |
| 服务层 | `*-service.cjs`（stock/fund/distribution/promotion/invoice/finance），承载业务规则。 |
| 鉴权中间件 | `authz.cjs` 的 `authenticate / requirePermission / scopeMerchant` 等。 |
| 响应结构 | `{ code, message, data }`，成功 `code=200`，参数错误 `code=400`，越权 `403`，未登录 `401`。 |
| 分页参数 | 入参兼容 `current/size` 与 `pageNum/pageSize`，返回 `records/total`。 |
| 基点 bp | 万分之一，`500bp=5%`。 |
| 行级隔离 | 通过 `merchantId/supplierId/distributorId` 过滤，越权返回 403。 |
| 幂等 | 重复支付、重复回调、重复入库、重复退款审核均不得重复产生资金/库存变化。 |
| 惰性转态 | Mock 无定时任务，查询/结算时把到期的 PENDING 佣金转为 SETTLEABLE。 |
| 回归脚本 | `verify*.cjs`，直连 8080 或自起独立端口的 Mock 进程。 |
